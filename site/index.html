🐟 Aura Pleco

The background cleaner fish daemon for Linux & Windows workstations — keeping memory, temp storage and local AI model caches crystal clear.

Get it on GitHub 1-click install

Why your workstation tanks

Inactive apps hoard RAMElectron utilities, browsers and IDEs hold physical memory they no longer use — your free RAM quietly evaporates.
AI dev leaves gigabytes behindStale Hugging Face weights, aborted Ollama pulls, PyTorch/Triton compile caches and *.partial blobs pile up in silence.
Windows Standby clogsThe Standby List never flushes itself; "available" memory stays locked in cache.
Temp junk accumulatesTest runs, playwright profiles and tmpfs litter fill storage between reboots.

What Pleco does — every 20 seconds

RAM SentinelWatches memory headroom; when it drops below threshold it compacts pages, drops inactive caches and flushes Standby memory.
Model Cache ScrubberCleans stale Hugging Face / Ollama / PyTorch Inductor / Triton artifacts — only incomplete and abandoned ones, never your models.
Working Set TrimmerAsks the OS to release unreferenced pages from background processes — nothing gets killed.
Gravel CleanerSweeps stale test dirs (playwright profiles, tmpfs litter) older than 2 hours.
Tank LogEverything it frees is logged — you always see exactly what the fish ate.

1-click install

# 🐧 Linux / Aura OS
git clone https://github.com/DusanCar-sudo/aura-pleco.git
cd aura-pleco/packages/linux
./install.sh          # or: ./install.sh --with-model  (bundles the local 1.8 GB LFM3-1.7B model)

# 🪟 Windows 10/11 — no Visual Studio needed (uses the built-in csc.exe)
# open PowerShell as Administrator, from packages\windows:
install.bat           # compiles in ~2s, registers a boot task, starts swimming
